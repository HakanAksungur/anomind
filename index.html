About the Project

Anomind aims to detect potentially malicious activity in network traffic and system logs using supervised and unsupervised machine learning techniques.

The platform will use a Large Language Model to generate evidence-based security incident summaries in Turkish, explaining what happened, which logs support the detection, and what actions security analysts should consider.

Core Capabilities

Anomaly Detection

Machine learning-based analysis of network and system logs.

LLM Investigation

Evidence-based incident explanations and recommendations.

Security Dashboard

Centralized alert management and security event monitoring.
